## Architecture and DNS deadline repair

- `native/src/cli.rs` and `native/src/retrieval.rs` move store-independent validation and search tokenization into `PreparedSearch`, `PreparedRead`, and `PreparedSources` before any cache open or bootstrap.
- `native/src/distribution.rs` owns `ManifestLocation`, `NetworkPolicy`, `TransferPolicy`, `LoadedManifest`, `AcquiredArtifact`, and one private detached `std::thread` transfer worker per remote operation (`TransferRequest`, `TransferEvent`, `RemoteTransfer`) communicating over a capacity-one `std::sync::mpsc::sync_channel` with `recv_timeout` and an `Arc<AtomicBool>` cancellation flag.
- Inside the worker, each hop validates URL policy, resolves non-literal domains synchronously via `system_resolve`, checks HTTP `localhost` loopback exclusivity, pins the exact returned addresses via `resolve_to_addrs`, installs an immediate-error `reqwest::dns::Resolve` fallback, and builds a direct-only `reqwest` `0.13.5` blocking Rustls client (`no_proxy()`, `redirect::Policy::none()`, `retry::never()`, `no_gzip`, `no_brotli`, `no_deflate`, `no_zstd`, `Accept-Encoding: identity`).
- One absolute deadline (`10s` connect capped by remaining budget, `30s` manifest, `300s` artifact) bounds DNS resolution, client initialization, redirect hops and redirect client drops, response headers, bounded body chunks (`1 MiB + 1` manifest sentinel, `compressedBytes + 1` artifact sentinel), and inner-scope `Client`/`Response` destruction before `TransferEvent::Finished`.
- The caller retains `.sync.lock` ownership, `.incoming.zst.tmp` staging and drop cleanup, SHA-256 hashing, decompression, validation, activation, and CLI output. On timeout, the caller drops `RemoteTransfer`, releases its lock, and returns without joining the detached worker. An already-blocked OS `getaddrinfo` call is uncancellable at the OS boundary and exits when the finite CLI process exits rather than blocking CLI return; repeated calls inside a long-lived embedded process are not bounded by a global worker cap. Direct-only `no_proxy()` ignores environment and OS proxies, so corporate proxy setups are unsupported and unverified.
- `native/src/snapshot.rs` delegates intake to `distribution`, excludes `.incoming.zst.tmp` from projected `storageBytes`, implements lock-rechecked `ensure_current_store` cold bootstrap, and adds manifest-only `sync_dry_run`.
- `native/src/domain.rs` adds `OFFLINE_REQUIRED` (exit 2), `TRANSFER_FAILED` (exit 4), and `TRANSFER_TIMEOUT` (exit 4), and updates remedies for `PATH_OR_HTTPS_URL`.
- `native/src/bin/clec-publish.rs` adds optional `--artifact-url` without changing default publisher output bytes when omitted.
- `native/examples/clec_test_fixture.rs` and `TestFixtureOptions` provide feature-gated (`test-hooks`) test controls for shortened timeouts, fixture CA trust, injected default manifest URLs, and deterministic resolver/setup/cleanup delay hooks absent from the shipped `clec` binary.
- `evaluation/clec-v1/phase4/PROTOCOL.md`, `evaluation/clec-v1/phase4/verify_phase4.py`, `evaluation/clec-v1/phase4/verify_dns_deadline.py`, and `evaluation/clec-v1/phase4/capture_http_capacity.py` establish the tracked protocol and rerunnable verification harness.
