# Stage 5 Native SAG2 Implementation Report

Stage 5 adds explicit `clec search --sag2` retrieval (`sag2_native_v1`) using a shared bounded HTTP worker (`http_transport.rs`), strict Jev Decisions wire validation (`sag2/jev.rs`), one local lexical expansion round, greedy Cholesky DPP top-10 ranking, native raw-blob rematerialization, tagged mode output, conservative pre-I/O minimum-envelope output admission, and whole-item output budgeting. Default `clec search`, corpus format `clec-native-v2`, Stage 4 static distribution policy, and Stage 3 quality findings remain unchanged.
