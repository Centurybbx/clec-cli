# CLEC 本地资料库：已确认的设计

本文件记录 2026-11-07 讨论并确认的方向。本地索引、语义检索及 Agent 命令已实现，使用方式和目前的限制见 [README](../README.md)。全库已生成逐字导航摘录；观点级摘要目前仅完成小样本试运行，尚未覆盖全库。

## 目标

为现有 CLEC 材料提供可追溯的本地检索、时间线和问答支持。保留不同时间、条件、说话人和来源之间的差异；不承诺全网资料或检索结果绝不遗漏。

## 数据

- 保留原始字幕、逐字稿、网页和讲义，不用整理稿覆盖原文。统一记录来源 ID、原始路径及哈希、类型、日期和日期依据、提取方法、质量状态、定位信息。
- 原文与用于搜索的繁简归一化文本分开；未知的日期、讲者、页码和时间戳保持未知。字幕时间仅属于对应字幕或确认过的媒体版本。
- 按字幕段或正文结构分段，保留原始定位与上下文。记录提取成功、内容是否为空及是否校对；隔离的异常转写不进入普通问答检索。
- 同一文件不同格式可以折叠展示，但保留所有来源；不同剪辑、转写版本和不同时间的表达不因标题或编号相似而自动合并。候选对应关系保留证据及待核对状态。

## 检索与回答

- 使用 Python 与可重建的 SQLite 本地索引；支持繁简体、节目编号、基金代码、关键词及时间筛选。中文短词设置回退，并通过样本验证。
- 提供供 Agent 使用的 `search`、`read`、`source`、`timeline`、`status` 操作。先搜索，再展开原文上下文与来源；引用指向可确认的原文件及定位。
- 先生成单篇摘要，再生成主题与时间线摘要；摘要用于导航，具体结论须回查原文。区分讲者、来信与第三方转述；发现说法不同时保留时间和条件，证据不足时说明无法判断。
- 先用“退休现金与现金流”等真实问题验证召回、去重、归因、引用与缺证回答，再扩展至完整资料；是否增加语义检索由实际漏检决定。首版无需网站、向量数据库或独立 AI 服务。
