# CLI 0.2.0 试用交付

目标是一个用户或 Agent 安装后可以直接操作、组合和恢复错误的本地工具。独立公开仓库为 https://github.com/Centurybbx/clec-cli ，首个公开提交为 `d611f97cba242bbf30a692c367d7cbdff4590eff`。原始语料、数据库、旧后端和本地评估记录没有上传。

## 已完成的产品边界

- `help`、各命令 `--help`、`version` 不要求安装语料。默认文本，显式 `--format json` 返回带版本的统一协议。
- 搜索、来源发现、来源章节、原文读取分别提供独立命令。批量读取支持位置参数和换行 stdin，保留顺序；任一输入失败时不输出部分结果。
- 失败仅写 stderr，包含代码、说明和恢复建议；退出状态区分参数、数据不可用、传输/文件系统、完整性和内部错误。关闭的下游管道正常退出。
- 搜索先对完整候选集合按来源限额，再分页；来源发现不合并相似标题的不同版本。后续分页可以固定数据版本。
- 预览优先定位原文中的字面匹配；读取默认附相邻章节，各自保留原文、UTF-16 范围和引用。质量、日期依据仍按存储的来源信息呈现。
- 同步成功后记住 manifest；再次 `sync` 不必重新传地址。配置保存失败但数据已激活时，会明确报告实际状态。

架构为 `命令输入 → commands.ts → cli.ts 分派 → corpus.ts / releases.ts → output.ts`。解析及帮助共用命令描述；证据和生命周期由原有领域模块负责。没有新服务、向量模型或持久索引，数据库格式、原文和引用规则保持不变。

## 验证证据

最终安装包 SHA-256：`e62f9ce23e84910e5998aa350f8c07508b30ea5f49ed6d4c6cdfe88c50e950dd`。

该包及校验文件已上传 [v0.2.0 试用发布](https://github.com/Centurybbx/clec-cli/releases/tag/v0.2.0)。已用公网 HTTPS 地址完成隔离安装，并另行下载核对 SHA-256 一致；安装后的帮助、版本及未配置数据的状态提示均通过。发布状态为 prerelease，源代码对应上述首个公开提交。

在仓库外安装实际包后，macOS arm64 的 Node 22.19.0 和 25.7.0 均通过 16 组真实进程检查，包括管道、批量原子失败、两侧上下文精确范围、分页、来源过滤、错误分类、首次/重复/失败同步及激活后的配置保存失败。完整语料的数据库哈希始终未变。检查脚本为 `evaluation/cli-product/verify.py`。

[公开 CI](https://github.com/Centurybbx/clec-cli/actions/runs/43410728783) 的 Linux、macOS、Windows × Node 22.19.0、24 六组均通过构建、类型检查、小型自建语料流程和打包后安装执行。跨平台 CI 使用的是自建小型语料，不等于完整语料跨平台验证。

10 个冻结的开发查询使用相同的前五条结果预算，旧版与新版均在 9 题中找到指定支持来源；D08 仍未在前五条找到。D07 的结果由同一来源占满改善为三个不同来源，其他题的来源数量未变。这只证明导航行为，不能解释为答案准确率提升。

六个新的最终问题在实现前冻结；实现者未接触题目与答案。新 Agent 只读取公开说明、问题和 CLI 返回内容，每题使用 3 次调用，均低于 22 KiB 返回内容和 14 秒调用时间。控制器实际限制每题 12 次调用、256 KiB 返回内容、180 秒；它不是操作系统沙箱，其他访问限制依赖 Agent 指令。答案和调用日志已先哈希冻结，再交独立评审。

独立评审结果为 5 题通过、1 题部分通过、0 题失败。部分通过的一题事实内容有支持，但读到的版本无法确认发言人归属，Agent 如实保留了不确定性。另有一题的代码在两份版本间不同，实际引用版本支持该答案，评审保留了版本差异。这是六个指定问题的试用结果，不是总体正确率，也没有同题旧版对照，不能宣称回答准确率提高。所有问题的调用预算与冻结哈希检查通过。

## 本机直接使用

已安装 `/Users/century/.local/bin/clec`，新登录 shell 可以直接找到 0.2.0，无需修改 shell 配置。

```sh
clec status
clec sources '退休'
clec search '退休 提領' --format json
clec help read
```

默认数据位于 `~/.local/share/clec`，包含 6,775 份来源、30,565 个章节。保存的本地发布清单位于 `~/.local/share/clec-releases/<release>/manifest.json`。稳定目录与已有验证数据库使用硬链接，核对 inode 和哈希后确认没有额外复制整库。数据库本体仍为 527,507,456 字节，约 503 MiB；更新可临时保留当前和候选两份。

正常命令在禁止网络、禁止写入数据目录的环境中完成搜索和读取。禁止所有文件系统写入时搜索报 SQLite I/O 错误；本轮不承诺完全没有可写临时工作空间的运行环境。

## 仍然存在的边界

公开仓库提供工具，尚未提供公开语料 manifest。新用户可以安装 CLI，但需要另行取得数据清单；“只给 GitHub 链接便自动获得这份完整语料”的数据分发环节尚未完成。没有发布 npm registry 包。

检索仍是词法检索，存在漏召回；默认相邻上下文不能保证条件完整，长逐字稿仍需要继续导航。答案由使用工具的 Agent 组织，必须保留日期、条件和来源归属。旧工具的评论/网页介绍检索和字幕时间定位尚未迁移。旧语料、索引和运行时没有删除。
